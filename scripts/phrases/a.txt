# 短句的變化（node scripts/build-phrases.mjs 產生 src/data/phrase-ext.json）
# 短句本身在 src/data/phrases.tsv；這裡用原文對應，加上變數、挖空題、回應題，學習紀錄還是算在原句
# 檔名是情境代號（a 招呼・寒暄、i 自我介紹…，見 src/words.js 的 PHRASE_CATS）
#
# == 短句原文（跟 phrases.tsv 一字不差）
# @原文片段|中文片段=$值表        變數：每次出題從值表抽一個，日文、讀音、中文一起換
#                                  值表在 scripts/dialogs/pools.txt（跟會話共用），也可以直接寫 =值;值，值寫成 日文=讀音/中文
#                                  原句的值會自動加進去；日→中、中→日會多一個「同一句、值不一樣」的錯誤選項
# ?cloze 挖空的原文[#第幾個][/答案說明]|錯誤選項;…
#                                  錯誤選項跟語法題一樣：漢字(讀音)，選項跟句子裡同一個漢字可以不標；/說明；開頭 ! 是錯誤用法
#                                  說明沒寫的查 scripts/phrases/gloss.txt → scripts/grammar/gloss.txt → 短句庫
# ?cloze *                         挖掉變數，錯誤選項是變數的其他值（要看中文才知道是哪個）
# ?reply 角色|對方說的話|中文|錯誤回應;…
#                                  答案就是這個短句；錯誤回應寫短句原文就直接用那句的讀音和中文，不然寫 日文(讀音)/中文
# 錯誤選項的原則跟語法題一樣：放進去一定錯（文法錯，或跟情境、中文對不上），兩個都說得通的不能一起出現；
# 回應題的錯誤回應不要用「はい」「そうですか」這種什麼情況都接得上的話
