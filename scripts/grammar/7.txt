# 語法題庫 N1（一）助詞、動詞變化、形容詞・名詞、疑問詞、敬語（格式見 1.txt 開頭）
# N1 很多是書面語，句子盡量用簡單的單字，只在文法本身需要時才用比較難的詞

# ======== 助詞 ========

== wo-motte|5|p|〜をもって|以…（手段、根據）；在…（時間點）結束|①名詞＋をもって：以…（手段、方法，正式）（書面をもって通知する）②時間＋をもって：在這個時間點結束（本日をもって閉店）。をもちまして 是更客氣的說法。
本日(ほんじつ){をもって}、この店(みせ)は閉店(へいてん)いたします。|本店將於今天結束營業。|をめぐって;をよそに;をものともせず
結果(けっか)は、書面(しょめん){をもって}お知(し)らせします。|結果將以書面通知。|をよそに;をめぐって;を皮切りに
これ{をもちまして}、本日(ほんじつ)の会議(かいぎ)を終(お)わります。|今天的會議就到此結束。|を皮切りに;をよそに;をものともせず

== wo-kagiri-ni|5|p|〜を限りに|以…為限（最後一次）|名詞（今日、今回）＋を限りに：以這個時間點為最後，之後就不再…（今日を限りに、たばこをやめる）。
今日(きょう){を限(かぎ)りに}、たばこをやめる。|從今天起戒菸（今天是最後一次）。|をよそに;をものともせず;をめぐって
今回(こんかい)の大会(たいかい){を限(かぎ)りに}、引退(いんたい)します。|這次大會之後就引退。|をよそに;をものともせず;をめぐって
この試合(しあい){を限(かぎ)りに}、彼(かれ)はチームを去(さ)る。|這場比賽之後，他就要離開球隊。|をよそに;をものともせず;をめぐって

== wo-sakai-ni|5|p|〜を境に|以…為分界（前後完全不同）|名詞＋を境に：以某個時間點、事件為界線，前後狀況大不相同（あの日を境に）。
あの事故(じこ){を境(さかい)に}、彼(かれ)は車(くるま)に乗(の)らなくなった。|自從那次事故之後，他就不再開車了。|をよそに;をものともせず;に即して
40歳(よんじゅっさい){を境(さかい)に}、体力(たいりょく)が落(お)ちてきた。|過了 40 歲，體力就開始下降了。|をよそに;をものともせず;に即して
結婚(けっこん){を境(さかい)に}、生活(せいかつ)が大(おお)きく変(か)わった。|以結婚為分界，生活有了很大的變化。|をよそに;をものともせず;に即して

== ni-sokushite|5|p|〜に即して|依照…（事實、規定）|名詞＋に即して：依照事實、規則、實際情況來做（事実に即して、法律に即して）。後面接名詞時用 に即した。
事実(じじつ){に即(そく)して}、報告(ほうこく)してください。|請依照事實報告。|をよそに;にひきかえ;を皮切りに
規則(きそく){に即(そく)して}、判断(はんだん)します。|依照規則判斷。|をよそに;にひきかえ;を皮切りに
現実(げんじつ){に即(そく)した}計画(けいかく)を立(た)てるべきだ。|應該擬定符合現實的計畫。|に反した;をめぐる;に代わる

== wo-fumaete|5|p|〜を踏まえて|根據…、考慮到…|名詞＋を踏まえて：把某件事當作前提、根據來思考、行動（調査の結果を踏まえて）。
調査(ちょうさ)の結果(けっか){を踏(ふ)まえて}、計画(けいかく)を見直(みなお)した。|根據調查結果重新檢討了計畫。|をよそに;をものともせず;を限りに
去年(きょねん)の失敗(しっぱい){を踏(ふ)まえて}、今年(ことし)は早(はや)めに準備(じゅんび)した。|考慮到去年的失敗，今年提早做了準備。|をよそに;を限りに;にひきかえ
皆様(みなさま)のご意見(いけん){を踏(ふ)まえて}、新(あたら)しいルールを作(つく)りました。|參考了各位的意見，制定了新規則。|をよそに;を限りに;にひきかえ

== ni-kakawaru|5|p|〜にかかわる|關係到…（重大的事）|名詞＋にかかわる：跟生命、名譽等重要的事有關，影響很大（命にかかわる病気）。
これは命(いのち){にかかわる}問題(もんだい)だ。|這是攸關性命的問題。|に足る;に値する;にひきかえ
そんなことをしたら、会社(かいしゃ)の信用(しんよう){にかかわる}。|做那種事的話，會影響公司的信譽。|に足る;に値する;!にかかわれる
個人(こじん)のプライバシー{にかかわる}質問(しつもん)には、お答(こた)えできません。|涉及個人隱私的問題，恕難回答。|に足る;に値する;にひきかえ

== ni-ataisuru|5|p|〜に値する|值得…|名詞、辭書形＋に値する：有做某件事的價值（尊敬に値する、読むに値する）；否定是 に値しない。
彼(かれ)の努力(どりょく)は、尊敬(そんけい){に値(あたい)する}。|他的努力值得尊敬。|にかかわる;に即する;に限る
この本(ほん)は、一度(いちど)読(よ)む{に値(あたい)する}。|這本書值得一讀。|にかかわる;に即する;に足らない
この映画(えいが)は、見(み)る{に値(あたい)しない}。|這部電影不值得看。|にかかわらない;!に値さない;!に値しなく

== ni-taeru|5|p|〜に堪える・〜に堪えない|值得…／不堪…；非常…|①辭書形、名詞＋に堪える＝值得（鑑賞に堪える）②に堪えない＝看不下去、聽不下去（見るに堪えない）③感謝、後悔＋に堪えない＝非常（感謝に堪えない）。
彼(かれ)の悪口(わるぐち)は、聞(き)く{に堪(た)えない}。|他說的壞話，讓人聽不下去。|に値する;にかかわる;!に堪えらない
皆様(みなさま)のご支援(しえん)には、感謝(かんしゃ){に堪(た)えません}。|對各位的支持，感激不盡。|に値します/值得…;にかかわります/關係到…;!に堪えれません
これは、大人(おとな)の鑑賞(かんしょう){に堪(た)える}作品(さくひん)だ。|這是經得起大人欣賞的作品。|にかかわる;に即する;!に堪えれる

== ni-tariru|5|p|〜に足る|足以…、值得…|辭書形、名詞＋に足る：有足夠的價值、條件（信頼するに足る人）；取るに足らない＝微不足道。
彼(かれ)は信頼(しんらい)する{に足(た)る}人物(じんぶつ)だ。|他是值得信賴的人。|にかかわる;に堪えない;にひきかえ
そんなことは、取(と)る{に足(た)らない}問題(もんだい)だ。|那種事是微不足道的問題。|にかかわらない;に堪えない;!に足らなく
これは、満足(まんぞく)する{に足(た)る}結果(けっか)とは言(い)えない。|這稱不上是令人滿足的結果。|にかかわる;に堪えない;にひきかえ

== wo-monotomosezu|5|p|〜をものともせず（に）|不顧…（困難），勇敢地…|名詞＋をものともせず：不把困難、危險當一回事，勇敢地面對（けがをものともせず）。用來描述別人。
彼(かれ)はけが{をものともせず}、最後(さいご)まで走(はし)った。|他不顧受傷，一直跑到了最後。|を踏まえて;に即して;を限りに
激(はげ)しい雨(あめ){をものともせず}、選手(せんしゅ)たちは試合(しあい)を続(つづ)けた。|選手們不顧大雨，繼續比賽。|を踏まえて;に即して;を限りに
周囲(しゅうい)の反対(はんたい){をものともせず}、彼女(かのじょ)は留学(りゅうがく)を決(き)めた。|她不顧周圍的反對，決定去留學。|を踏まえて;に即して;を限りに

== wo-yoso-ni|5|p|〜をよそに|不顧…、無視…|名詞＋をよそに：不在意別人的擔心、期待或周圍的狀況（親の心配をよそに）。
親(おや)の心配(しんぱい){をよそに}、息子(むすこ)は毎晩(まいばん)遊(あそ)び歩(ある)いている。|兒子不顧父母的擔心，每天晚上在外面玩。|を踏まえて;を皮切りに;に即して
住民(じゅうみん)の反対(はんたい){をよそに}、工事(こうじ)が始(はじ)まった。|不顧居民的反對，工程開始了。|を踏まえて;を皮切りに;に即して
周(まわ)りの期待(きたい){をよそに}、彼(かれ)は試合(しあい)に出(で)なかった。|他無視周圍的期待，沒有出賽。|を踏まえて;を皮切りに;に即して

== wo-kawakiri-ni|5|p|〜を皮切りに|以…為開端（接著一連串）|名詞＋を皮切りに：以某件事為開始，接著同類的事一個接一個發生（東京を皮切りに、全国でコンサートを行う）。
東京(とうきょう){を皮切(かわき)りに}、全国(ぜんこく)でコンサートを行(おこな)う。|以東京為首站，在全國舉辦演唱會。|をよそに;を限りに;をものともせず
彼(かれ)の発言(はつげん){を皮切(かわき)りに}、いろいろな意見(いけん)が出(で)た。|以他的發言為開端，各種意見都出來了。|をよそに;を限りに;をものともせず
この店(みせ){を皮切(かわき)りに}、駅前(えきまえ)に新(あたら)しい店(みせ)が次(つぎ)から次(つぎ)へとできた。|以這家店為開端，車站前接連開了新店。|をよそに;を限りに;をものともせず

== ni-shite|5|p|〜にして|到了…才；既是…又是…|①名詞＋にして＝到了這個程度、階段才…（60歳にして初めて）②既是…同時也是…（医者にして作家）③就連…也（プロにして難しい）。

== ni-itatte-wa|5|p|〜に至っては|至於…（更極端的例子）|名詞＋に至っては：在一群例子中，舉出最極端的那一個（みんな遅刻した。田中に至っては、来もしなかった）。
