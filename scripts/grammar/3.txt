== ni-tsuite|3|p|〜について|關於…|說、想、調查的內容（歴史について調べる、将来について話す）。
日本(にほん)の歴史(れきし){について}調(しら)べています。|正在查關於日本歷史的資料。|にとって;によって;として

== ni-totte|3|p|〜にとって|對…來說|從某人的立場、角度來看（私にとって大切、子供にとって難しい）。
私(わたし){にとって}、家族(かぞく)がいちばん大切(たいせつ)です。|對我來說，家人最重要。|によって;について;に対(たい)して
この問題(もんだい)は子供(こども){にとって}難(むずか)しすぎます。|這個問題對小孩來說太難了。|によって;について;として
留学生(りゅうがくせい){にとって}、日本(にほん)の生活(せいかつ)は大変(たいへん)です。|對留學生來說，日本的生活很辛苦。|によって;について;に対(たい)して

== to-shite|3|p|〜として|作為…、以…的身分|身分、立場、資格（留学生として来た、趣味として習う）。

== ni-taishite|3|p|〜に対して|對（某人）…|態度、動作的對象（学生に対して厳しい、客に対して失礼）。「にとって」是從某人的立場看。
先生(せんせい)は学生(がくせい){に対(たい)して}とても厳(きび)しいです。|老師對學生很嚴格。|にとって;について;によって
お客様(きゃくさま){に対(たい)して}、失礼(しつれい)なことを言(い)ってはいけません。|不可以對客人說失禮的話。|にとって;について;として
田中(たなか)さんは、だれ{に対(たい)して}も親切(しんせつ)です。|田中先生對誰都很親切。|にとって;について;として

== ni-yotte|3|p|〜によって|由…；因…而不同；由於…|被動句的動作者（ピカソによって描かれた）；依…而不同（人によって違う）；原因（台風によって）。

国(くに){によって}、習慣(しゅうかん)が違(ちが)います。|習慣因國家而不同。|にとって;について;として

== koso|3|p|〜こそ|正是…、…才是|強調「就是這個」（今度こそ＝這次一定）；回應對方的客氣話（こちらこそ＝我才要…）。

健康(けんこう){こそ}、いちばん大切(たいせつ)なものです。|健康才是最重要的。|さえ;しか;ばかり

== ni-kurabete|3|p|〜に比べて|跟…比起來|名詞＋に比べて：跟某個東西比較（去年に比べて、今年は暑い）。

== kurai-teido|3|p|〜くらい・〜ほど（程度）|…到…的程度|普通形＋くらい（ぐらい）／ほど：用比喻、例子表示程度很高（泣きたいくらい痛い、死ぬほど疲れた）。

== tte|3|p|〜って（口語）|…這個（＝とは）；聽說…（＝と言っていた）|口語裡 って 可以代替 とは、という、と（言っていた）、は：「わさびって何？」「明日休むって。」

== shieki-ukemi|3|v|使役被動|被迫…、被叫去…|使役＋被動，表示不情願地被迫做某事：五段 う段→あ段＋される（飲む→飲まされる，す結尾用 させられる）；一段：去る＋させられる（食べさせられる）；する→させられる。
子供(こども)のころ、母(はは)に嫌(きら)いな野菜(やさい)を{食(た)べさせられました/被逼著吃（使役被動）}。|小時候被媽媽逼著吃討厭的蔬菜。|食べさせました/讓…吃（使役）;食べられました/被吃掉（被動）;!食べられさせました
