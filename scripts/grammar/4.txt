# 語法題庫 N2（一）助詞類（格式見 1.txt 開頭）
# N2、N1 意思相近的文法很多（一…就…、雖然、因為…都有好幾種），錯誤選項只用意思明顯不同的，或接法錯誤的

# ======== 助詞 ========

== ni-kanshite|4|p|〜に関して・〜に関する|關於…（正式）|跟 について 意思一樣，比較正式；後面接名詞時用 に関する（環境に関する本）。
この問題(もんだい){に関(かん)して}、ご意見(いけん)はありますか。|關於這個問題，您有什麼意見嗎？|に反して;に加えて;に代わって
環境(かんきょう){に関(かん)する}本(ほん)を読(よ)みました。|讀了一本關於環境的書。|に反する;に代わる;をこめた
事故(じこ){に関(かん)して}、警察(けいさつ)が調(しら)べています。|警察正在調查有關事故的事。|を問わず;に限らず;に加えて
新(あたら)しい商品(しょうひん){に関(かん)する}質問(しつもん)は、こちらへどうぞ。|有關新商品的問題，請到這邊來。|に反する;に代わる;をこめた

== wo-megutte|4|p|〜をめぐって|圍繞著…（爭論、議論）|很多人對某件事有不同意見，在爭論、討論的時候用。
新(あたら)しい駅(えき)の場所(ばしょ){をめぐって}、住民(じゅうみん)の意見(いけん)が分(わ)かれています。|圍繞著新車站的位置，居民的意見分歧。|をこめて;に代わって;を問わず
遺産(いさん){をめぐって}、兄弟(きょうだい)がけんかになった。|兄弟為了遺產吵了起來。|をこめて;に代わって;に限って
この計画(けいかく){をめぐって}、会議(かいぎ)で激(はげ)しい議論(ぎろん)が行(おこな)われた。|會議上針對這個計畫進行了激烈的討論。|をこめて;に代わって;を問わず

== ni-oite|4|p|〜において・〜における|在…（正式）|＝で 的正式說法，用在場所、時間、領域；後面接名詞時用 における。
入学式(にゅうがくしき)は体育館(たいいくかん){において}行(おこな)われます。|入學典禮在體育館舉行。|に対して;に関して;につれて
日本(にほん){における}外国人(がいこくじん)の数(かず)は増(ふ)えている。|在日本的外國人人數正在增加。|に対する;によって;をこめた
現代社会(げんだいしゃかい){において}、インターネットはなくてはならないものだ。|在現代社會中，網路是不可或缺的東西。|に対して;につれて;をこめて
この分野(ぶんや){において}、彼(かれ)はとても有名(ゆうめい)だ。|在這個領域，他非常有名。|に対して;につれて;をこめて

== ni-watatte|4|p|〜にわたって|長達…、遍及…|前面接時間、範圍（3日間、全国）：在整個範圍裡一直、到處都…。後面接名詞時用 にわたる。
会議(かいぎ)は3日間(みっかかん){にわたって}行(おこな)われた。|會議一連舉行了三天。|に際して;に先立って;をきっかけに
台風(たいふう)で、広(ひろ)い範囲(はんい){にわたって}停電(ていでん)した。|因為颱風，大範圍停電了。|に際して;に先立って;をきっかけに
10年(じゅうねん){にわたる}研究(けんきゅう)の結果(けっか)、新(あたら)しい薬(くすり)が完成(かんせい)した。|經過長達 10 年的研究，新藥完成了。|!にわたって;に対する;をこめた

== ni-kakete|4|p|〜から〜にかけて|從…到…（大概的範圍）|時間、地點的大概範圍，沒有 から〜まで 那麼明確。

== ni-motozuite|4|p|〜に基づいて|根據…（依據）|以某個資料、規則、事實為依據來做（データに基づいて判断する）。後面接名詞時用 に基づく。

== wo-moto-ni|4|p|〜をもとに（して）|以…為基礎、素材|把某個東西當作素材、參考，做出新的東西（経験をもとにした小説）。

== ni-sotte|4|p|〜に沿って|沿著…；按照…|①沿著河、路（川に沿って歩く）②按照方針、希望去做（計画に沿って進める）。
