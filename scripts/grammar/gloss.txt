# 語法選項的中文說明：日文/說明（題目裡沒寫 /說明 的選項查這裡）
# 寫的是這個字詞「本身」的作用，答完會顯示在每個選項底下

# ---- 助詞 ----
は/主題：「…呢／至於…」，提出要說的話題
が/主語：指出「是誰／是什麼」（疑問詞、存在、喜好的對象）
を/動作的對象（吃什麼、看什麼）；離開、經過的地方
に/時間點；目的地；存在的地方；對象（給誰、見誰）
で/動作發生的地方；手段、工具、語言
へ/方向：往…
と/和…；跟…一起
も/也
の/的（名詞＋の＋名詞）
か/疑問（…嗎）；或
や/…和…等等（舉幾個例子）
から/從…（起點）；因為…
まで/到…（終點、持續到某時）
までに/在…之前（期限）
より/比…
ほど/（接否定）沒有…那麼…
しか/只…（後面一定接否定）
だけ/只…
ばかり/光是…、淨是…
ごろ/（時間點）…左右
ぐらい/（數量、時間長度）大約
ね/語尾：…呢、…吧（希望對方同意）
よ/語尾：…喔（告訴對方不知道的事）
でも/（句首）但是；…之類的；疑問詞＋でも＝不管…都
こそ/正是…、…才是（強調）
さえ/連…都；（さえ〜ば）只要…就
にとって/對…來說（從某人的立場看）
によって/由…（被動的動作者）；因…而（不同）；由於…
について/關於…
として/作為…、以…的身分
に対して/對（某人）…（態度、動作的對象）

# ---- 指示詞・疑問詞 ----
これ/這個（單獨當名詞）
それ/那個（單獨當名詞，離對方近）
あれ/那個（單獨當名詞，離雙方都遠）
どれ/哪個（三個以上選一個）
この/這個（後面要接名詞）
その/那個（後面要接名詞）
あの/那個（後面要接名詞，離雙方都遠）
どの/哪個（後面要接名詞）
ここ/這裡
そこ/那裡（離對方近）
あそこ/那裡（離雙方都遠）
どこ/哪裡
こちら/這邊、這位（禮貌）
こう/這樣（副詞）
そう/那樣（副詞）
ああ/那樣（副詞）
どう/怎麼樣（後面接動詞、です）
こんな/這樣的（後面接名詞）
そんな/那樣的（後面接名詞）
あんな/那樣的（後面接名詞）
どんな/什麼樣的（後面接名詞）
どちら/哪一個（兩個選一個）；哪邊
なに/什麼
何/什麼
なん/什麼
だれ/誰
いつ/什麼時候
いくら/多少錢
いくつ/幾個；幾歲
どうして/為什麼

# ---- 副詞 ----
もう/已經
まだ/還（沒）、仍然
もっと/更…
また/又、再
よく/常常；好好地
いちばん/最…
とても/非常

# ---- 接續詞（でも 寫在助詞那裡）----
しかし/但是（書面）
だから/所以
それから/然後、接著
そして/而且；然後
それに/而且、再加上
それとも/還是（二選一的疑問）
それなのに/可是卻…（出乎意料、不滿）
ところが/然而（結果跟預期相反）
そのため/因此
