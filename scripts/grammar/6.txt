# ======== 句型・語氣 ========
# 判斷・推測

== ni-kimatte-iru|4|e|〜に決まっている|一定是…、肯定…|普通形、名詞＋に決まっている：說話者非常有把握的判斷，比 にちがいない 更主觀、口語。
こんなに安(やす)いのは、偽物(にせもの){に決(き)まっている}。|這麼便宜，一定是假貨。|に限る;に越したことはない;!に決まる
そんなに練習(れんしゅう)していないなら、負(ま)ける{に決(き)まっている}よ。|練習得那麼少的話，肯定會輸啦。|に限る;に越したことはない;!に決まる
彼(かれ)はまだ来(こ)ない。また寝坊(ねぼう)した{に決(き)まっている}。|他還沒來。一定又睡過頭了。|に限る;に越したことはない;!に決まる

== kkonai|4|e|〜っこない|絕不可能…|ます形去ます＋っこない：說話者強烈認為不可能（できっこない、分かりっこない）。口語。
こんな難(むずか)しい問題(もんだい)、子供(こども)に解(と)け{っこない}。|這麼難的題目，小孩不可能解得出來。|そうだ;!っこなく;!っこぬ
一日(いちにち)でこの本(ほん)を全部(ぜんぶ)覚(おぼ)えるなんて、でき{っこない}よ。|一天要背完這整本書，怎麼可能做得到。|そうだ;!っこなく;!っこぬ
いくら説明(せつめい)しても、あの人(ひと)には分(わ)かり{っこない}。|再怎麼解釋，那個人也絕對不會懂。|そうだ;!っこなく;!っこぬ

== osore|4|e|〜おそれがある|恐怕會…（有危險）|辭書形、名詞＋の＋おそれがある：有發生不好的事的可能性，新聞、氣象預報、說明書常用。
明日(あした)は大雨(おおあめ)になる{おそれがある}。|明天恐怕會下大雨。|ところだ;!おそれである;!おそれをする
この薬(くすり)を飲(の)むと、眠(ねむ)くなる{おそれがあります}。|吃了這個藥，恐怕會想睡覺。|ところです;!おそれでいます;!おそれをします
このままでは、この鳥(とり)は絶滅(ぜつめつ)の{おそれがある}。|再這樣下去，這種鳥恐怕會滅絕。|ところだ;!おそれである;!おそれをする

== to-wa-kagiranai|4|e|〜とは限らない|不一定…|普通形＋とは限らない：一般認為是這樣，但也有例外（高いものがいいとは限らない），常跟 必ずしも 一起用。
値段(ねだん)が高(たか)いものが、いいもの{とは限(かぎ)らない}。|價格貴的東西不一定是好東西。|に違いない;に決まっている;!とは限る
日本人(にほんじん)がみんな寿司(すし)が好(す)き{とは限(かぎ)らない}。|並不是所有日本人都喜歡壽司。|に違いない;に決まっている;!とは限る
天気予報(てんきよほう)が必(かなら)ず当(あ)たる{とは限(かぎ)らない}。|氣象預報不一定都準。|に違いない;に決まっている;!とは限る

== to-iu-mono-dewa-nai|4|e|〜というものではない・〜というものでもない|並不是…就好|普通形＋というものではない：某種想法並不一定正確（高ければいいというものではない）。
料理(りょうり)は、高(たか)ければいい{というものではない}。|料理並不是越貴就越好。|に決まっている;に違いない;ことだ
練習(れんしゅう)は、長(なが)くやればいい{というものでもない}。|練習並不是練得越久就越好。|に決まっている;に違いない;ことだ
お金(かね)があれば幸(しあわ)せになれる{というものではない}。|並不是有錢就能幸福。|に決まっている;に違いない;ことだ

== nai-koto-wa-nai|4|e|〜ないことはない・〜ないこともない|也不是不…|ない形＋ことはない：不是完全不行，還是有可能（行けないことはない＝也不是不能去），語氣不太積極。
少(すこ)し遠(とお)いけど、歩(ある)いて行(い)けない{ことはない}。|雖然有點遠，也不是不能走路去。|ことだ;ものだ;わけだ
辛(から)いものは、食(た)べられない{こともない}。|辣的東西也不是不能吃。|ことだ;ものだ;わけだ
ちゃんと説明(せつめい)すれば、分(わ)かってもらえない{ことはない}と思(おも)う。|好好說明的話，我想也不是沒辦法讓對方理解。|ことだ;ものだ;わけだ

== ni-hoka-naranai|4|e|〜にほかならない|正是…、無非是…|名詞、〜から＋にほかならない：斷定「不是別的，就是這個」（成功は努力の結果にほかならない）。にすぎない 是「只不過」，意思相反。
彼(かれ)が成功(せいこう)したのは、毎日(まいにち)の努力(どりょく)の結果(けっか){にほかならない}。|他之所以成功，正是每天努力的結果。|にすぎない;どころではない;!にほかならる
親(おや)が叱(しか)るのは、子供(こども)を愛(あい)しているから{にほかならない}。|父母會責罵，無非是因為愛孩子。|どころではない;とは限らない;!にほかならる
今回(こんかい)失敗(しっぱい)したのは、準備(じゅんび)が足(た)りなかったから{にほかならない}。|這次會失敗，無非是因為準備不夠。|どころではない;とは限らない;!にほかならる

== ni-sugi-nai|4|e|〜にすぎない|只不過是…|普通形、名詞＋にすぎない：只是這樣而已，沒什麼了不起（うわさにすぎない）。
それは、ただのうわさ{にすぎない}。|那只不過是傳聞罷了。|に限る;!にすぎる;!にすぎるない
私(わたし)は社長(しゃちょう)の言葉(ことば)を伝(つた)えた{にすぎません}。|我只不過是轉達了社長的話。|に限ります;!にすぎます;!にすぎりません
アルバイトの給料(きゅうりょう)は、月(つき)に5(ご)万円(まんえん){にすぎない}。|打工的薪水一個月只不過 5 萬日圓。|に限る;!にすぎる;!にすぎるない

== to-iu-mono-da|4|e|〜というものだ|這才叫…、真是…（評論）|普通形、名詞＋というものだ：說話者斷定「這就是…的本質、這樣才對」（困っている人を助けるのが、友達というものだ）。否定 というものではない 是另一個意思（並不是…就好）。
困(こま)っているときに助(たす)けるのが、本当(ほんとう)の友達(ともだち){というものだ}。|在困難的時候幫忙，才是真正的朋友。|にすぎない;どころではない;に決まっている
一度(いちど)失敗(しっぱい)しただけであきらめるのは、もったいない{というものだ}。|才失敗一次就放棄，真是太可惜了。|にすぎない;どころではない;に限る
そんなに急(きゅう)に言(い)われても、無理(むり){というものだ}。|突然這樣說，實在是強人所難。|にすぎない;どころではない;に限る

== mo-douzen|4|e|〜も同然だ|跟…一樣、幾乎等於…|名詞、普通形＋も同然だ：雖然實際上不是，但幾乎等於是（勝ったも同然、新品も同然）。
あと1点(いってん)取(と)れば、勝(か)った{も同然(どうぜん)だ}。|再拿 1 分，就等於贏了。|にすぎない;どころではない;ほかない
このパソコンは一度(いちど)しか使(つか)っていないから、新品(しんぴん){も同然(どうぜん)だ}。|這台電腦只用過一次，跟新的一樣。|にすぎない;どころではない;に限る
彼(かれ)は私(わたし)にとって、家族(かぞく){も同然(どうぜん)だ}。|他對我來說，就跟家人一樣。|にすぎない;どころではない;に限る

== toka|4|e|〜とか（聽說）|聽說…（好像）|普通形＋とか：不太確定地轉述聽來的消息，語氣比 そうだ 更不肯定。
田中(たなか)さん、来月(らいげつ)結婚(けっこん)する{とか}。|聽說田中先生下個月要結婚。|ものか;ことか;まい
昨日(きのう)の地震(じしん)で、駅(えき)の近(ちか)くの古(ふる)い家(いえ)が壊(こわ)れた{とか}。|聽說昨天的地震，車站附近的老房子倒了。|ものか;ことか;まい
あの店(みせ)のラーメンはとてもおいしい{とか}。今度(こんど)行(い)ってみよう。|聽說那家店的拉麵非常好吃。下次去吃吃看吧。|ものか;ことか;まい

== mai|4|e|〜まい|絕不…（決心）；大概不會…|辭書形＋まい（る動詞也可以用 ない形去ない＋まい：食べまい）：①決心不做（二度と行くまい）②推測不會（雨は降るまい）。書面語。
もう二度(にど)と、あの店(みせ)には行(い)く{まい}。|我絕對不會再去那家店了。|だろう;べきだ;つもりだ
この雨(あめ)は、明日(あした)までは続(つづ)く{まい}。|這場雨大概不會持續到明天。|べきだ;つもりだ;ばかりだ
彼(かれ)の気持(きも)ちは、誰(だれ)にも分(わ)かる{まい}。|他的心情，大概誰都不會懂吧。|べきだ;つもりだ;ばかりだ

== to-mieru|4|e|〜とみえる|看樣子…、似乎…|普通形＋とみえる（とみえて）：根據看到的情況推測別人的狀態，書面語（よほど疲れていたとみえて、すぐ寝てしまった）。
彼(かれ)はよほど疲(つか)れていた{とみえて}、すぐに寝(ね)てしまった。|他似乎非常累，馬上就睡著了。|くせに;ついでに;とたん
あの店(みせ)はいつも人(ひと)が並(なら)んでいる。よほどおいしい{とみえる}。|那家店總是有人在排隊。看樣子相當好吃。|に限る;にすぎない;ほかない
犬(いぬ)が鳴(な)いている。誰(だれ)か来(き)た{とみえる}。|狗在叫。看樣子有人來了。|に限る;にすぎない;ほかない

== ni-kakatte-iru|4|e|〜にかかっている|取決於…、全看…|名詞、〜かどうか＋にかかっている：結果要看這個東西而定（成功するかどうかは、努力にかかっている）。
試合(しあい)に勝(か)てるかどうかは、みんなの頑張(がんば)り{にかかっている}。|比賽能不能贏，全看大家的努力。|に限る;にすぎない;どころではない
この計画(けいかく)が成功(せいこう)するかどうかは、あなた{にかかっている}。|這個計畫能不能成功，就看你了。|に限る;にすぎない;どころではない
合格(ごうかく)できるかどうかは、これからの勉強(べんきょう){にかかっている}。|能不能考上，取決於接下來的學習。|に限る;にすぎない;どころではない

# 感情・感嘆

== zu-niwa-irarenai|4|e|〜ずにはいられない・〜ないではいられない|忍不住…|ない形去ない＋ずにはいられない（する→せずには）：感情上控制不住，一定會去做（笑わずにはいられない）。
あの映画(えいが)を見(み)ると、{泣(な)かずにはいられない/忍不住哭}。|看了那部電影，就忍不住會哭。|!泣きずにはいられない;!泣くずにはいられない;泣いてはいられない/不能一直哭下去
彼(かれ)の話(はなし)を聞(き)くと、{笑(わら)わずにはいられない/忍不住笑}。|一聽他說話，就忍不住笑出來。|!笑いずにはいられない;!笑うずにはいられない;笑ってはいられない/不能一直笑下去
困(こま)っている人(ひと)を見(み)ると、{助(たす)けないではいられない/忍不住去幫忙}。|一看到有困難的人，就忍不住想幫忙。|!助けないにはいられない;!助けずではいられない;助けてはいられない/不能一直幫下去
甘(あま)いものを見(み)ると、{食(た)べずにはいられない/忍不住吃}。|一看到甜食就忍不住要吃。|!食べないずにはいられない;!食べるずにはいられない;食べてはいられない/不能一直吃下去

== te-naranai|4|e|〜てならない・〜てたまらない・〜てしょうがない|…得不得了|て形＋ならない／たまらない／しょうがない（しかたがない）：某種感情、感覺非常強烈，控制不住（心配でならない、暑くてたまらない）。
息子(むすこ)のことが心配(しんぱい)で{ならない}。|非常擔心兒子。|はいけない;もいい;!なる
今日(きょう)は暑(あつ)くて{たまらない}。|今天熱得受不了。|はいけない;もいい;!たまらなく
彼女(かのじょ)に会(あ)いたくて{しょうがない}。|想見她想得不得了。|はいけない;もいい;!しょうがある
試験(しけん)の結果(けっか)が気(き)になって{しかたがない}。|非常在意考試的結果。|はいけない;もいい;!しかたがある

== koto-ka|4|e|〜ことか|多麼…啊|疑問詞（どんなに、何度）＋普通形＋ことか：強烈的感嘆（どんなにうれしかったことか）。
合格(ごうかく)の知(し)らせを聞(き)いて、どんなにうれしかった{ことか}。|聽到考上的消息，該有多開心啊。|ことだ;わけか;ばかりか
この日(ひ)を、何度(なんど)夢(ゆめ)に見(み)た{ことか}。|這一天，我在夢裡見過多少次啊。|ことだ;わけか;ばかりか
一人(ひとり)で外国(がいこく)に住(す)むのは、どんなに大変(たいへん)な{ことか}。|一個人住在國外，該有多辛苦啊。|ことだ;わけか;ばかりか

== koto-ni|4|e|〜ことに（は）|令人…的是|感情形容詞、動詞た形＋ことに：先說出說話者的感受（驚いたことに、残念なことに、うれしいことに）。
驚(おどろ)いた{ことに}、彼(かれ)は一人(ひとり)で全部(ぜんぶ)作(つく)ったそうだ。|令人吃驚的是，聽說他一個人全部做好了。|ついでに;くせに;以来
残念(ざんねん)な{ことに}、試合(しあい)は雨(あめ)で中止(ちゅうし)になった。|很遺憾的是，比賽因為下雨取消了。|ついでに;くせに;以来
うれしい{ことに}、今年(ことし)は家族(かぞく)みんなで旅行(りょこう)に行(い)ける。|令人高興的是，今年全家人能一起去旅行。|ついでに;くせに;以来

== mono-ka|4|e|〜ものか|才不…、絕不…|普通形＋ものか（口語：もんか、ものですか）：強烈否定，表示「絕對不會那樣」。
あんな店(みせ)、二度(にど)と行(い)く{ものか}。|那種店，我才不會再去第二次。|ことか;ものだ;わけだ
あんなやつに負(ま)ける{ものか}。|我才不會輸給那種傢伙。|ことか;ものだ;わけだ
「疲(つか)れた？」「疲(つか)れる{もんか}。まだまだ元気(げんき)だよ。」|「累了嗎？」「才不累。還很有精神呢。」|ことか;もんだ/（〜もんだ）本來就…;わけだ

== mono-ga-aru|4|e|〜ものがある|有…之處、讓人感到…|普通形＋ものがある：說話者從某件事感受到某種特別的東西（彼の歌には人の心を動かすものがある）。
彼(かれ)の歌(うた)には、人(ひと)の心(こころ)を動(うご)かす{ものがある}。|他的歌有一種打動人心的力量。|わけがない;ばかりだ;おそれがある
この絵(え)には、見(み)る人(ひと)を引(ひ)きつける{ものがある}。|這幅畫有一種吸引人的力量。|わけがない;ばかりだ;おそれがある
一人(ひとり)で外国(がいこく)に住(す)むのは、つらい{ものがある}。|一個人住在國外，有它辛苦的地方。|わけがない;おそれがある;までもない

== ba-yokatta|4|e|〜ばよかった|要是…就好了（後悔）|ば形＋よかった：對過去沒做的事感到後悔、遺憾（もっと勉強すればよかった）；なければよかった＝要是沒…就好了。
もっと早(はや)く家(いえ)を{出(で)ればよかった/要是…就好了（後悔）}。|要是早點出門就好了。|出てもよかった/（〜てもいい）也可以…;!出るばよかった;!出たばよかった
あんなこと、{言(い)わなければよかった/要是沒說就好了}。|要是沒說那種話就好了。|言ってもよかった/（〜てもいい）也可以說;!言わないばよかった;!言わなかればよかった
傘(かさ)を{持(も)ってくればよかった/要是帶來就好了}。|要是有帶傘來就好了。|持ってきてもよかった/（〜てもいい）也可以帶來;!持ってくるばよかった;!持ってこればよかった

== nai-mono-ka|4|e|〜ないものか・〜ないものだろうか|能不能…呢（強烈希望）|可能形的ない形＋ものか：非常希望能實現，在想有沒有辦法（何とかならないものか）。
何(なん)とかして、この病気(びょうき)を治(なお)せない{ものか}。|有沒有什麼辦法能治好這個病呢？|わけがない;ことはない;までもない
もう少(すこ)し安(やす)くならない{ものだろうか}。|能不能再便宜一點呢？|わけがない;ことはない;までもない
毎日(まいにち)の通勤(つうきん)が、もっと楽(らく)にならない{ものか}。|每天的通勤能不能更輕鬆一點呢？|わけがない;ことはない;までもない

# 建議・規範

== mono-da|4|e|〜ものだ|本來就…；以前常…；真是…啊|①辭書形＋ものだ＝本來就應該這樣（常識、道理）②た形＋ものだ＝以前常常…（回憶）③感嘆（時間がたつのは早いものだ）。
子供(こども)のころは、よくこの川(かわ)で遊(あそ)んだ{ものだ}。|小時候常在這條河裡玩呢。|ことだ;ところだ;わけがない
時間(じかん)がたつのは早(はや)い{ものです}ね。|時間過得真快啊。|ことです/（〜ことだ）最好…（忠告）;ところです/（〜ところだ）正要…;わけがありません/不可能…
人(ひと)の話(はなし)は、最後(さいご)まで聞(き)く{ものだ}。|別人說話，本來就應該聽到最後。|ところだ;わけがない;ものか

== mono-dewa-nai|4|e|〜ものではない|不應該…（一般道理）|辭書形＋ものではない：從常識、道德來說不應該做（人の悪口を言うものではない）。
人(ひと)の悪口(わるぐち)を言(い)う{ものではない}。|不應該說別人的壞話。|わけがない;どころではない;に決まっている
夜(よる)遅(おそ)く、人(ひと)の家(いえ)に電話(でんわ)する{ものではない}。|不應該在深夜打電話到別人家。|わけがない;どころではない;に決まっている
食(た)べ物(もの)を粗末(そまつ)にする{ものではありません}。|不應該糟蹋食物。|わけがありません/不可能…;どころではありません/哪有心思…;に決まっています/肯定…
