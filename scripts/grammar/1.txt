# 語法題庫 N5（node scripts/build-grammar.mjs 產生 src/data/grammar.json）
#
# == 代號|難度|分類|文法|意思|說明
#   代號：小寫英數和 -，學習紀錄靠它對應，寫好就不要改
#   難度：1=N5 2=N4 3=N3 4=N2 5=N1
#   分類：p 助詞 | v 動詞變化 | a 形容詞・名詞 | q 指示・疑問詞 | j 接續・條件 | e 句型・語氣 | g 授受・敬語
#   文法、意思：列表和弱點顯示用（〜てください／請…）；說明：答完才顯示，寫用法重點、跟容易搞混的差在哪
#   同一個難度裡各分類輪流出題，分類內照檔案順序（先學的寫前面，例如 て形 要在〜てください 前面）
#
# 底下每行一句：日文|中文|錯誤選項;錯誤選項;…
#   日文用 {答案} 標出挖空的地方；漢字（含數字）後面用半形括號標讀音：毎朝(まいあさ)6時(ろくじ){に}起(お)きます。
#   錯誤選項至少 3 個，多於 3 個時每次隨機挑 3 個
#   錯誤選項要「放進句子一定錯」：文法上不通，或意思跟中文對不上；兩個都說得通的（に／へ、から／ので）不能同時出現
#   選項（含答案）的說明寫在後面 /說明；沒寫的查 gloss.txt
#   開頭加 ! 是錯誤的變化或接法（書きて、静かくて），說明自動填「錯誤用法」
#   選項裡跟句子同一個詞的漢字可以不標讀音（沿用句子的；来 依後面的假名判斷 き／こ／く）
#   為了專心在文法：單字盡量用 N5 的常用字，同一個字在不同句子裡重複用沒關係

# ======== 助詞 ========

== wa|1|p|は|主題（…是…）|「AはBです」：A 是這句話要說的主題，B 是對它的說明。は 當助詞時唸 wa。
私(わたし){は}学生(がくせい)です。|我是學生。|を;に;で;へ
これ{は}私(わたし)の本(ほん)です。|這是我的書。|を;で;へ;に
田中(たなか)さん{は}先生(せんせい)です。|田中先生是老師。|を;に;で;へ
今日(きょう){は}暑(あつ)いですね。|今天很熱呢。|を;で;へ
あの店(みせ){は}安(やす)いです。|那家店很便宜。|を;で;へ

== no|1|p|の|的（名詞＋の＋名詞）|名詞修飾名詞時中間要加 の：私の本、日本語の先生、日本のお茶。中文的「的」有時省略（日語老師），日文的 の 不能省。
これは私(わたし){の}かばんです。|這是我的包包。|は;を;に;で
山田(やまだ)さんは日本語(にほんご){の}先生(せんせい)です。|山田先生是日語老師。|が;を;で;に
友達(ともだち){の}家(いえ)へ行(い)きます。|要去朋友家。|を;で;へ
これは日本(にほん){の}お茶(ちゃ)です。|這是日本的茶。|を;に;で
駅(えき){の}前(まえ)で待(ま)っています。|在車站前面等。|を;が;へ

== mo|1|p|も|也|も 取代 は、が、を：私も学生です、みかんも好きです、パンも食べます。
私(わたし){も}学生(がくせい)です。|我也是學生。|を;で;へ
田中(たなか)さんは行(い)きます。私(わたし){も}行きます。|田中先生要去。我也要去。|を;で;に
りんごが好(す)きです。みかん{も}好きです。|喜歡蘋果。也喜歡橘子。|に;で;へ
昨日(きのう)は雨(あめ)でした。今日(きょう){も}雨です。|昨天下雨。今天也是雨天。|を;に;へ
パンを食(た)べました。卵(たまご){も}食べました。|吃了麵包。也吃了蛋。|に;で;へ

== wo|1|p|を|動作的對象|吃什麼、看什麼、買什麼：動作直接作用的東西用 を。を 當助詞時唸 o。
毎朝(まいあさ)、コーヒー{を}飲(の)みます。|每天早上喝咖啡。|に;で;へ
図書館(としょかん)で本(ほん){を}読(よ)みます。|在圖書館看書。|に;で;が
友達(ともだち)に手紙(てがみ){を}書(か)きます。|寫信給朋友。|に;で;へ
毎日(まいにち)日本語(にほんご){を}勉強(べんきょう)します。|每天學日語。|に;へ;が
スーパーで野菜(やさい){を}買(か)いました。|在超市買了蔬菜。|に;で;へ

== ni-time|1|p|に|時間點|有數字的時間（6時、3月、日曜日）後面加 に；今日、明日、毎朝、来週 這類相對的時間不加。
毎朝(まいあさ)6時(ろくじ){に}起(お)きます。|每天早上 6 點起床。|で;を;へ
日曜日(にちようび){に}映画(えいが)を見(み)ます。|星期天看電影。|で;を;へ
夜(よる)11時(じゅういちじ){に}寝(ね)ます。|晚上 11 點睡覺。|で;を;が
3月(さんがつ){に}日本(にほん)へ行(い)きます。|3 月要去日本。|で;を;が
授業(じゅぎょう)は9時(くじ){に}始(はじ)まります。|課 9 點開始。|で;を;へ

== e-ni|1|p|へ・に|方向、目的地|行く、来る、帰る 的目的地用 へ 或 に，兩個都可以。へ 當助詞時唸 e。
明日(あした)、京都(きょうと){へ}行(い)きます。|明天要去京都。|と;で;が
7時(しちじ)に家(いえ){に}帰(かえ)ります。|7 點回家。|で;を;が
友達(ともだち)が日本(にほん){へ}来(き)ます。|朋友要來日本。|で;を;は
毎朝(まいあさ)8時(はちじ)に学校(がっこう){に}行(い)きます。|每天早上 8 點去學校。|で;を;が

== de-place|1|p|で|動作發生的地方|在哪裡「做」某件事（讀書、吃飯、玩）用 で；只是「在、有」（いる、ある）用 に。
図書館(としょかん){で}勉強(べんきょう)します。|在圖書館讀書。|に;を;へ
公園(こうえん){で}サッカーをします。|在公園踢足球。|に;を;へ
駅(えき)の前(まえ){で}友達(ともだち)を待(ま)ちます。|在車站前面等朋友。|を;へ;が
レストラン{で}昼(ひる)ご飯(はん)を食(た)べます。|在餐廳吃午餐。|に;を;へ
台所(だいどころ){で}料理(りょうり)を作(つく)ります。|在廚房做菜。|に;を;へ

== ni-de|1|p|に・で|存在的地方／動作的地方|いる、ある、住む 用 に（在哪裡）；讀書、工作、吃飯 這些動作用 で（在哪裡做）。「東京で住んでいます」「会社に働いています」是常見的錯誤。
猫(ねこ)は部屋(へや){に}います。|貓在房間裡。|で;を;へ
部屋(へや){で}本(ほん)を読(よ)みます。|在房間看書。|に;を;へ
東京(とうきょう){に}住(す)んでいます。|住在東京。|で;を;へ
会社(かいしゃ){で}働(はたら)いています。|在公司工作。|に;を;へ
机(つくえ)の上(うえ){に}本(ほん)があります。|桌上有書。|で;を;へ
公園(こうえん){で}写真(しゃしん)を撮(と)りました。|在公園拍了照。|に;を;へ

== de-means|1|p|で|手段、工具、語言|坐什麼交通工具、用什麼東西、用什麼語言：バスで、はしで、日本語で。
バス{で}学校(がっこう)へ行(い)きます。|坐公車去學校。|を;に;へ
はし{で}ご飯(はん)を食(た)べます。|用筷子吃飯。|を;に;が
日本語(にほんご){で}話(はな)してください。|請用日語說。|に;が;へ
ペン{で}名前(なまえ)を書(か)きます。|用筆寫名字。|を;が;へ
電話(でんわ){で}レストランを予約(よやく)しました。|用電話預約了餐廳。|を;に;が

== ga-exist|1|p|が|（有…）あります・います 的主語|「場所に 東西が あります／います」：有什麼東西用 が。東西用 ある，人和動物用 いる。
机(つくえ)の上(うえ)にりんご{が}あります。|桌上有蘋果。|を;で;へ
公園(こうえん)に子供(こども){が}います。|公園裡有小孩。|を;で;へ
私(わたし)は兄(あに){が}二人(ふたり)います。|我有兩個哥哥。|を;で;へ
駅(えき)の近(ちか)くに銀行(ぎんこう){が}あります。|車站附近有銀行。|を;で;へ
冷蔵庫(れいぞうこ)に牛乳(ぎゅうにゅう){が}あります。|冰箱裡有牛奶。|を;で;へ

== ga-like|1|p|が|好き・上手・分かる・ほしい 的對象|喜歡、擅長、懂、想要的東西用 が，不用 を：猫が好きです、日本語が分かります、車がほしいです。
私(わたし)は猫(ねこ){が}好(す)きです。|我喜歡貓。|を;で;に
田中(たなか)さんは料理(りょうり){が}上手(じょうず)です。|田中先生很會做菜。|を;で;へ
私(わたし)は日本語(にほんご){が}少(すこ)し分(わ)かります。|我懂一點日語。|を;で;へ
新(あたら)しい車(くるま){が}ほしいです。|想要新車。|を;で;に
弟(おとうと)は野菜(やさい){が}嫌(きら)いです。|弟弟討厭蔬菜。|を;で;へ

== ga-question|1|p|が|疑問詞當主語（誰、什麼…）|「だれが」「何が」「どれが」：疑問詞當主語一定用 が，回答時也用 が，不能用 は。
だれ{が}来(き)ましたか。|誰來了？|は;を;に
どれ{が}田中(たなか)さんの傘(かさ)ですか。|哪一把是田中先生的傘？|は;を;に
何(なに){が}いちばんおいしいですか。|什麼最好吃？|は;を;に
「だれが窓(まど)を開(あ)けましたか。」「田中(たなか)さん{が}開けました。」|「誰開了窗戶？」「是田中先生開的。」|は;を;に
どこ{が}痛(いた)いですか。|哪裡痛？|は;を;で

== ka|1|p|か|疑問（…嗎）；或|句尾加 か 變成問句；名詞 か 名詞＝A 或 B。
これは何(なん)です{か}。|這是什麼？|ね;よ;も
明日(あした)、学校(がっこう)へ行(い)きます{か}。|明天要去學校嗎？|よ;を;で
コーヒー{か}紅茶(こうちゃ)を飲(の)みます。|喝咖啡或紅茶。|と/和;を;に
田中(たなか)さんは学生(がくせい)です{か}。|田中先生是學生嗎？|よ;を;に

== to|1|p|と|和；跟…一起|名詞と名詞＝A 和 B（全部列出來）；人と＝跟誰一起。
友達(ともだち){と}映画(えいが)を見(み)ました。|跟朋友看了電影。|を;で;へ
パン{と}牛乳(ぎゅうにゅう)を買(か)いました。|買了麵包和牛奶。|を;で;が
来週(らいしゅう)、家族(かぞく){と}旅行(りょこう)します。|下週要和家人去旅行。|を;で;へ
母(はは){と}一緒(いっしょ)に料理(りょうり)を作(つく)りました。|跟媽媽一起做了菜。|を;で;へ

== ya|1|p|や|…和…等等（舉例）|や 只舉幾個例子，還有別的沒說完，常跟 など 一起用；と 是全部列出來。
かばんの中(なか)に本(ほん){や}ノートなどがあります。|包包裡有書、筆記本等等。|を;で;に
週末(しゅうまつ)は掃除(そうじ){や}洗濯(せんたく)をします。|週末會打掃、洗衣服等等。|を;で;が
スーパーで肉(にく){や}野菜(やさい)を買(か)いました。|在超市買了肉和蔬菜等等。|を;で;が
机(つくえ)の上(うえ)にペン{や}辞書(じしょ)などがあります。|桌上有筆、字典等等。|を;で;へ

== kara-made|1|p|から・まで|從…到…|から 是起點（時間、地方），まで 是終點：9時から5時まで、家から駅まで。
授業(じゅぎょう)は9時(くじ){から}です。|課從 9 點開始。|まで;に;で
銀行(ぎんこう)は3時(さんじ){まで}です。|銀行開到 3 點。|から;に;で
家(いえ){から}駅(えき)まで歩(ある)きます。|從家走到車站。|まで;に;を
東京(とうきょう)から大阪(おおさか){まで}新幹線(しんかんせん)で行(い)きます。|從東京坐新幹線到大阪。|から;を;が
月曜日(げつようび){から}金曜日(きんようび)まで働(はたら)きます。|從星期一工作到星期五。|まで;に;を

== ni-target|1|p|に|對象（給誰、見誰、問誰）|動作的對象是人：友達に会う、母に電話する、先生に聞く。「友達を会う」是常見的錯誤。
友達(ともだち){に}会(あ)います。|和朋友見面。|を;で;へ
母(はは){に}電話(でんわ)をかけます。|打電話給媽媽。|を;で;や
先生(せんせい){に}質問(しつもん)します。|問老師問題。|を;で;や
弟(おとうと){に}本(ほん)をあげました。|給了弟弟書。|を;で;や
友達(ともだち){に}メールを送(おく)りました。|傳了郵件給朋友。|を;で;や

== ni-enter|1|p|に|進入、搭乘、坐的地方|乗る、入る、座る 的地方用 に：電車に乗る、お風呂に入る、いすに座る。

== wo-leave|1|p|を|離開、經過的地方|出る、降りる 離開的地方；渡る、歩く、散歩する 經過的地方，都用 を。

この道(みち){を}まっすぐ行(い)ってください。|請沿著這條路直走。|に;が;と

== goro-gurai|1|p|ごろ・ぐらい|大約|時間「點」用 ごろ（3時ごろ）；數量、時間「長度」用 ぐらい（10分ぐらい、3つぐらい）。
駅(えき)まで10分(じゅっぷん){ぐらい}かかります。|到車站大約要 10 分鐘。|ごろ;まで;から
毎日(まいにち)2時間(にじかん){ぐらい}勉強(べんきょう)します。|每天讀書大約 2 小時。|ごろ;より;から
3時(さんじ){ごろ}電話(でんわ)します。|3 點左右打電話。|だけ;ほど;しか
りんごを5個(ごこ){ぐらい}買(か)いました。|買了大約 5 個蘋果。|ごろ;まで;から

== ne-yo|1|p|ね・よ|…呢／…喔（語尾）|ね＝希望對方同意、跟對方確認（いい天気ですね）；よ＝告訴對方不知道的事、提醒對方（財布が落ちましたよ）。
「今日(きょう)は暑(あつ)いです{ね}。」「ええ、本当(ほんとう)に。」|「今天好熱呢。」「是啊，真的。」|よ;か;を
あ、財布(さいふ)が落(お)ちました{よ}。|啊，你的錢包掉了喔。|ね;を;で
このケーキ、おいしいです{ね}。|這個蛋糕好好吃呢。|よ;か;を
明日(あした)はテストです{よ}。忘(わす)れないでください。|明天要考試喔。請不要忘記。|ね;か;を

== no-mono|1|p|の（代替名詞）|…的（東西）|の 可以代替前面說過或大家都知道的名詞：私の（我的）、赤いの（紅色的）、日本のです（日本製的）。
この傘(かさ)は私(わたし){の}です。|這把傘是我的。|は;を;が
「どのシャツがいいですか。」「その赤(あか)い{の}がいいです。」|「哪件襯衫好？」「那件紅色的好。」|は;を;で
このかばんは高(たか)いです。もっと安(やす)い{の}はありませんか。|這個包包很貴。有沒有更便宜的？|を;が;で
この時計(とけい)は日本(にほん){の}です。|這支錶是日本製的。|は;が;を

# ======== 動詞變化 ========

== masu-tense|1|v|ます・ました・ません・ませんでした|動詞的時態（禮貌形）|現在、未來用 ます；過去用 ました；否定 ません；過去否定 ませんでした。「食べないでした」是常見的錯誤。
昨日(きのう)、映画(えいが)を{見(み)ました/看了（過去）}。|昨天看了電影。|見ます/看（現在、未來）;見ません/不看;見ませんでした/沒看（過去否定）
明日(あした)、友達(ともだち)に{会(あ)います/（明天）會見面}。|明天要和朋友見面。|会いました/見面了（過去）;会いませんでした/沒見面;会いません/不見面
今朝(けさ)は何(なに)も{食(た)べませんでした/沒吃（過去否定）}。|今天早上什麼都沒吃。|食べました/吃了;食べます/吃（現在、未來）;!食べないでした
私(わたし)はお酒(さけ)を{飲(の)みません/不喝（習慣）}。|我不喝酒。|飲みました/喝了;飲みます/喝;飲みませんでした/（那時）沒喝
先週(せんしゅう)は学校(がっこう)へ{行(い)きませんでした/沒去（過去否定）}。|上週沒去學校。|行きません/不去（現在、未來）;行きました/去了;!行かないでした

== te-form|1|v|て形的變化|書く→書いて、読む→読んで…|く→いて、ぐ→いで、う・つ・る→って、む・ぶ・ぬ→んで、す→して；行く 例外是 行って。
ここに名前(なまえ)を{書(か)いて/書く→書いて（く→いて）}ください。|請在這裡寫名字。|!書きて;!書って;!書いで
