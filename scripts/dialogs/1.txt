# 會話題庫原始資料（由 scripts/build-dialogs.mjs 轉成 src/data/dialogs.json，改完執行 npm run build:dialogs）
# 每段是一個「範本」：人名、時間、數量、地點、物品用變數，出題時隨機帶入；劇情可以分支；題目從候選題裡抽
#
# === 編號|難度(1 入門 2 基礎 3 進階)|情境|標題
# 變數：
#   @名稱=$共用表            從 pools.txt 的值表抽（同一張表抽出的變數彼此不重複）
#   @名稱=@另一個變數         跟另一個變數用同一份值表、值不重複
#   @名稱=值;值;值           值寫成 日文=讀音/中文（沒有漢字可省略讀音），前面可加 代號: 給條件用
#   @名稱~另一個變數=值;值    跟另一個變數同一組（第幾個值就配第幾個，例如數量配總價）
#   %名稱=a;b                劇情分支，隨機選一個
# 句子：說話者代號|角色名稱|日文|讀音|中文
#   日文、讀音、中文、角色都能用 {名稱}；讀音裡 {名稱} 的位置要跟日文一樣；沒有漢字的句子讀音可以留空
# 題目（第幾句從 0 起算，有條件的句子也要算進去）：
#   ?cloze|第幾句|挖空的原文|錯誤選項;…   挖空寫 {名稱} 時挖掉變數（要能從別句推出來），* 用它的其他值當錯誤選項
#                                         同一句出現好幾次的字寫 に#2 指定挖第幾個
#   ?reply|第幾句|錯誤回應;…              藏起那句，從選項選出最合理的
#   ?read|中文問題|正確答案|錯誤;…        答案有 {名稱} 時，* 用它的其他值當錯誤選項
#   錯誤選項可以多於 3 個，出題時隨機挑 3 個；含漢字的日文選項寫成 漢字=讀音
# 條件：句子或題目前面加 [名稱=a]、[名稱!=a]、[名稱=a,b]，只在那個劇情出現
# 每段寫 4 題以上，出題時隨機抽（入門、基礎 3 題，進階 4 題），盡量每種題型都有
